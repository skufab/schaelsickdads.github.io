Termin eintragen

Einmal einrichten, dann geht es mit einem Tipp. Der Schlüssel bleibt nur auf diesem Gerät.

  1. Bei GitHub einloggen und hier einen neuen Schlüssel anlegen.
  2. Name: Termine. Gültig bis: 1 Jahr.
  3. Repository access: „Only select repositories" und wählen.
  4. Permissions → Repository permissions → Contents: „Read and write".
  5. Ganz unten Generate token, den Schlüssel kopieren und hier einfügen.
